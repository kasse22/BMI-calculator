# BMI Calculator

A simple and responsive **BMI Calculator** built with **HTML, CSS, and JavaScript**.

## Features

* Calculate BMI using height and weight
* Display BMI value
* Show BMI category
* Provide a short explanation for each category
* Simple and clean user interface
* Responsive design

## BMI Categories

| BMI         | Category      |
| ----------- | ------------- |
| Below 15    | Very Low BMI  |
| 15 – 18.4   | Underweight   |
| 18.5 – 24.9 | Normal Weight |
| 25 – 29.9   | Overweight    |
| 30+         | Obesity       |

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Use

1. Enter your height in centimeters.
2. Enter your weight in kilograms.
3. Click **Calculate BMI**.
4. Your BMI, category, and explanation will be displayed.
